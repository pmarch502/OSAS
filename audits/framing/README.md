# Framing audits

Reports from `prompts/framing_audit.md`, one file per chapter audited. They
record where a post-first-century theological framework may be doing work in
an exegesis chapter.

**These are reports, not corrections.** Nothing here has been acted on unless
`prompts/corrections_log.md` says so. A finding becomes a change only through
the correction workflow in CLAUDE.md, with the project author's approval.

A verdict of `clean` is a real result and is kept, not deleted — the point of
the exercise is as much to establish where the exegesis holds as where it
drifts.
